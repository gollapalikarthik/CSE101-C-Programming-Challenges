# Challenge 01 – Student Marks Calculator

## Problem Statement

Write a C program to calculate the total marks, average marks, and percentage obtained by a student in five subjects: English, Physics, Mathematics, Biology, and Chemistry.

Each subject has a maximum of 100 marks.

## Algorithm

1. Start the program.
2. Declare variables to store the marks of five subjects.
3. Read the marks of English, Physics, Mathematics, Biology, and Chemistry.
4. Calculate the total marks.
5. Calculate the percentage using:
   Percentage = (Total / 500) × 100
6. Calculate the average marks using:
   Average = Total / 5
7. Display the total marks, percentage, and average marks.
8. Stop the program.
